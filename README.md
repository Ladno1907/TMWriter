# TMWriter

Fullstack-приложение для автоматизации промышленного кобота **Techman Robot (TM5-700)**, превращающее робота в векторный графопостроитель. Приложение принимает произвольный текст из веб-интерфейса, рассчитывает его геометрию по сетке поля и транслирует в траектории движения манипулятора.

Проект работает в связке с кастомным транспортным драйвером [techman-js](https://github.com/Ladno0719/techman-js).

## Ключевая функциональность

* **Векторные шрифты на JSON:** Реализован собственный парсер кастомных шрифтов, где каждый символ описан массивом элементарных геометрических команд (`up`, `down`, `line`, `blend`, `circle`).
* **Динамический маппинг текста:** Алгоритм автоматически разбивает строку на слова, переносит строки по границам физического рабочего поля манипулятора и масштабирует координаты глифов с сохранением пропорций.
* **Интерактивный HTML5 Canvas предпросмотр:** Фронтенд на чистом JS имитирует поведение робота, отрисовывая сетку ячеек и будущую траекторию движения маркера (включая сглаживание углов `blend` и дуги `circle`).
* **Конвейерная обработка буфера сокетов:** Так как буфер команд робота ограничен 15 тегами (`QueueTag`), сервер реализует асинхронный опрос состояния (`ResponseTracker`) и подливает новые буквы в память робота по мере выполнения старых.

## Инструкция по запуску

### 1. Линк локальной зависимости (techman-js)
Так как драйвер `techman-js` является локальной разработкой и не опубликован в публичном npm-регистре, его необходимо связать с текущим проектом через `npm link`.

Сначала перейдите в директорию с библиотекой драйвера и создайте глобальную ссылку:
```bash
cd ../techman-js
npm run build
npm link
```

Затем перейдите в директорию **TMWriter** и подключите пакет:
```bash
cd ../TMWriter
npm link techman-js
```

### 2. Установка остальных зависимостей
```bash
npm install
```

### 3. Запуск в режиме разработки
```bash
npm run dev
```
Сервер запустится на `http://localhost:3000`.

### 4. Сборка и Production старт
```bash
npm run build
npm start
```

## Конфигурация шрифта (Пример глифа)

Символы описываются в формате JSON. Пример структуры для буквы "Г":
```json
"Г": [
  { "cmd": "line", "x": 1, "y": 1 },
  { "cmd": "down" },
  { "cmd": "line", "x": 1, "y": 11 },
  { "cmd": "line", "x": 7, "y": 11 },
  { "cmd": "up" }
]
```
